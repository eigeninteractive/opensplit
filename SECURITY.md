# Security policy

## Supported versions

Security fixes ship in the latest Android release on
[Google Play](https://play.google.com/store/apps/details?id=com.eigeninteractive.opensplit)
and the current [web app](https://opensplit.eigeninteractive.com/app). If you
find an issue in an older Android release, include that version in your report.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/eigeninteractive/opensplit/security/advisories/new).
Include the affected platform and app version, what happened, and steps to
reproduce the issue with sample data. Use the private report for follow-up
and redact credentials and personal expense data.
