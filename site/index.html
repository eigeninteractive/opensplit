FAQ

Questions people actually ask.

Is OpenSplit really free?
Yes — no subscription tier, no ads, no paywalled features. It's licensed AGPL-3.0 and maintained by contributors, not investors.
Can I run my own server?
Yes. Self-hosting instructions live in the GitHub repository's README — clone it, point the app at your instance, done.
What license is the code under?
AGPL-3.0. You can use, modify, and redistribute it, but any modified version run as a network service must also share its source.
Can I contribute?
Always — issues and pull requests are welcome on GitHub. It's a community project.
