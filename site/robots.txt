# /app is deliberately NOT disallowed here, though nothing under it belongs in
# an index. Every path under it returns the same single-page shell with a 200,
# so left alone it would offer an unbounded set of URLs that are all the same
# document. The shell answers that itself, with `robots: noindex` — and it can
# only answer if it is fetched. Disallowing it here would block the fetch, and
# a page this one links to twice would then be eligible for listing with no
# snippet, which is the outcome the rule was meant to prevent.
